# Bienvenido a Sportmatch ⚽

Sportmatch es una plataforma integral diseñada para facilitar la búsqueda, reserva y gestión de canchas deportivas. Este sistema conecta a usuarios deportistas con dueños de establecimientos a través de una interfaz moderna y eficiente.

## Acerca de este sitio

En este portal de documentación encontrarás todo lo necesario para entender, operar y desplegar la plataforma Sportmatch. La documentación está dividida en tres áreas clave para satisfacer los criterios del proyecto:

### 1. [Manual de Usuario](usuario.md)
Guía paso a paso sobre cómo interactuar con la plataforma desde la perspectiva de un cliente (búsqueda de canchas, geolocalización, trazado de rutas, reservas) y desde la perspectiva de un administrador (dashboard de estadísticas y paginación).

### 2. [Documentación Técnica](tecnica.md)
Detalles arquitectónicos del proyecto. Incluye las guías de instalación, descripción de las tecnologías utilizadas (React, Vite, Spring Boot) y explicación de la estructura del código y los servicios (ej. consumo de OSRM para rutas).

### 3. [Declaración de uso de Inteligencia Artificial](declaracion_ia.md)
Transparencia sobre las herramientas asistidas por IA utilizadas durante el ciclo de desarrollo (Antigravity/Gemini), destacando qué módulos fueron desarrollados en Pair-Programming, los prompts utilizados y la supervisión técnica humana aplicada.
